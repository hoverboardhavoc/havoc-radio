Havoc Radio Installer

WiFi install

A K-Radio on the stock firmware installs Havoc Radio from its own update menu. Nothing is opened or soldered. The install takes about five minutes.

Connect the K-Radio to Havoc

Open the network setup

On the K-Radio, press the knob to open the menu. Turn to the page ringed in red and press. Turn one step to the web page method and press. Do not press the QR code method: it locks the knob for 100 s.

Join K-Radio from the phone

The K-Radio shows these two screens in turn. Join the phone to K-Radio and open http://192.168.4.1.

Enter Havoc

Enter Havoc as the WiFi name (WiFi 名称), leave the password empty, and press 确认配置.

Wait for the restart

The K-Radio confirms and restarts. Join the phone to Havoc again to follow the install here.

Run the update

Start the update

Open the menu again, turn to the page ringed in red, and press.

Download

The K-Radio downloads Havoc Radio. The bar at the top of this page shows the progress.

Install

The K-Radio installs Havoc Radio and restarts into it. Keep it switched on until the Havoc Radio splash shows.
If it does not work

If the K-Radio shows this, it could not join Havoc. Move the installer within a few metres and enter the name again.

If it shows this, the update did not run and nothing changed. Run the update again.

A download that stopped early changes nothing. "Refused: no image" means the installer carries no image the WiFi install can use; see the Installer page.

UART install

The installer writes Havoc Radio through the K-Radio's UART header U15 and verifies every region. This works on any K-Radio, even one that does not start.

Fit the header

If U15 is empty, solder in a 2×3 right-angle 2.54 mm pin header.

Wire it up

Wire the installer to the header as in the diagram, with five female-to-female Dupont jumper wires. Leave VIN unconnected.
Wiring diagram

Install

Switch the K-Radio on and press Install. The installer puts it into download mode, writes each region, checks it and restarts the K-Radio.
RegionResult
If it does not work

If the K-Radio does not answer, check that it is switched on and that the wires match the diagram. TX goes to RX: GPIO4 to RXD, GPIO5 to TXD.

If a region still fails after three rewrites, press Install again.

The console must be disconnected while installing, on this page and any other.

Console

This page shows the K-Radio's serial output over the UART wires. Connect, then press Reset to see the boot log.

How

Reset restarts the K-Radio's firmware. Download mode restarts it into the ROM loader. The boot ROM, the bootloader and Havoc Radio all print at 74880 baud.

Only one thing can use the serial port at a time. While the console is connected, the UART install is refused. esptool reaches the same port at socket://192.168.4.1:3333.

How

Upload a file that is written at flash offset 0x0, such as radio/build/havoc-radio-install.bin from make install-image. The image survives a restart. Keep the page open until it says the image is stored.

The WiFi install needs an install image. It starts with byte 0xE9, is at most 3,731,456 bytes, and carries the start-up image at 0x1000 that lets the stock firmware boot it. Any other image works only over UART.

Home network

The installer can also join a home network. This page then works from any computer on it. The access point Havoc stays on. WiFi installs keep working while the installer is joined.

How

Choose installer/build/installer.bin from make installer, not havoc-radio-installer.bin. The installer writes it next to the running firmware, checks it and restarts. The new firmware confirms itself after 30 seconds; if it restarts before then, the installer returns to the previous firmware. The home network and the carried image stay as they are.
