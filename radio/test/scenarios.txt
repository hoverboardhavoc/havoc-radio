# UI scenarios. Each one starts at power-on (splash at t=0) from the prototype's demo state and is replayed
# both in the prototype (tools/gen_goldens.py, which writes test/golden/<name>[_<label>].pbm) and in the
# firmware UI (host tests), which must render the same frames.
#
#   scenario NAME
#   [@T] OP [ARGS]     T in ms since power-on; without @T a line runs 100 ms after the previous one,
#                      and the first line of a scenario runs at 3000 ms.
#   OPs: turn N | hold N | press | long | side | render [LABEL]
#        set bars N | set ssb 0|1 | set wifi off | set lang CODE | ota | empty
#        rds sync 0|1 | rds pty N | rds ps TEXT | rds rt TEXT | rds ab   (RDS as the decoder hands it to the
#        UI: PS and RadioText in display form; ab is an A/B flag change, which clears the RadioText)
#        ntp HH:MM   (an NTP sync at that UTC time on 2026-11-10; the clock then runs on the scenario time)
#        set server TEXT   (the NTP server setting)
